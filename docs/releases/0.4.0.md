# Mouse Style 0.4.0

First public candidate for Omarchy with **Hyprland 0.56.2 and Lua configuration**.

- Switch between native Omarchy, experimental Mac and Windows pointer styles.
- Adjust each style's settings, restore defaults, and retain independent
  preferences across sessions. Changes use 15-second trials with Keep/Revert.
- Choose Letter, Code or Hidden (icon only) bar labels. The original Flow bar icon and active profile
  header follow the Omarchy theme. Hardware DPI stays unchanged.
- One installer handles missing dependencies, both native modules, configuration
  integration, verification and rollback. Reinstall/repair retains preferences.
- Profile transitions and Keep no longer temporarily open the setup screen.

## Installation

```sh
omarchy plugin add https://github.com/ilysorc/omarchy-mouse-style.git --enable
```

Open Mouse Style in the bar and click **Install / Repair**. Alternatively extract
the attached source archive and run `./install.sh` as your desktop user. Setup
may request authentication for missing system packages. Matching Hyprland headers
are required; unsupported versions are rejected without bypassing ABI checks.

Run `mouse-style uninstall` for full removal before removing only the widget.
Preferences, recovery backups and shared system packages are retained.

## Validation and limits

Local validation passed 70 Python tests, 24 native tests, 1,280 Mac reference
samples, actual QML panel/setup tests, and native compilation on Hyprland 0.56.2.
Mac is based on measured Sequoia tables; exact macOS parity, broader hardware
coverage and other compositor versions are unverified. See README and
docs/PUBLISHING.md for the installation contract and evidence.
