# Pointer Feel documentation routing

This repository owns its product decisions, implementation notes, development
plan, research, and validation records. Keep those records here rather than
duplicating them in an external personal knowledge repository.

- Start with [README.md](README.md) for usage, installation, and validation.
- Use [docs/DESIGN.md](docs/DESIGN.md) for current product and technical decisions.
- Use [docs/ROADMAP.md](docs/ROADMAP.md) for progress, deferred requests, and next work.
- Use [docs/RESEARCH.md](docs/RESEARCH.md) and
  [docs/MAC-REFERENCE.md](docs/MAC-REFERENCE.md) for evidence and model limits.
- Read only the documents relevant to the task; update the existing authoritative
  record when behavior or a decision changes.

Product text, errors, CLI output, and project documentation are English and
vendor-neutral. Personal device preferences are not generic product defaults.
Distinguish user feedback, measured behavior, and upstream claims.

Brain may hold a short project entry with its identity, purpose, overall status,
and source paths, plus personal preferences or reusable knowledge. Do not copy
this repository's feature decisions, roadmap, or test ledger into Brain.
